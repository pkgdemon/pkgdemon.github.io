NextBSD kld → kext — raw module catalog

The unedited, first-pass catalog of all 474 FreeBSD loadable kernel modules in the NextBSD tree (sys/modules/) — one row per module: what it is, its category, and a proposed Apple-style org.nextbsd.* bundle id + .kext name. This is the source material that fed the polished naming + categorization plan (which splits these into the 343 kext candidates and 131 already-built-in, and frames the open decisions). Kept here verbatim as the groundwork record for #179.

2026-06-04. Source: read-only review of freebsd-src/sys/modules (474 modules) by 8 parallel review agents. Categories/purposes derived from each module’s Makefile .PATH + source. First-pass proposal, not a final mapping.

Columns: ko = real loaded module name (becomes CFBundleExecutable) · dir = sys/modules/ subdir · category · purpose · bundle id + kext = first-pass naming proposal · notes (“sub” / “fw” / “subdir” / “test” flag the open D3/D5 cases). For the resolved decisions and the built-in vs. kext split, see the naming plan.
