nextbsd-freebsd-compat: curated srclist → full buildworld

Retire the 594-line srclist.txt and rebuild nextbsd-freebsd-compat from a single make buildworld, packaged as the same one-big NextBSD-freebsd-compat artifact. Done in place — same repo, same package name, same tarball filename — so nextbsd-pkg and NextBSD-everything keep working and rollback is one git revert. This replaces the earlier new-repo (nextbsd-freebsd-world) variant: no repo swap, no dependency flip, no archive dance.

Status: planning — PR-ready. Synthesised from a 4-agent sweep (2026-07-03): pipeline audit, data-derived strip-list (measured on cowsurgery 15.0-p9 × NextBSD-userland plist), buildworld/CI design, and downstream impact. Every path in §4 is verified against a running box.

Why One evening of gershwin bring-up cost three emergency PRs (#43 locales, #44 diff/m4/patch/install/top/ncurses, #45 gzip), each a base tool nobody remembered to list. srclist.txt already carries 20+ "replaces FreeBSD-X" comments — it is a hand-typed, incomplete reimplementation of pkgbase. Additive curation does not converge. A full world does.

2. The build rework

Delete (all in build.yml, per the audit): the srclist.txt extraction; the /stage mkdir skeleton enumeration (installworld's mtree lays the hierarchy); the entire krb5 manual-staging block + stage_for_build() helper + the per-dir case krb5/* special-casing; and the per-dir obj/all/install loop. The explicit toolchain+_includes warm-up step is subsumed by buildworld.

Replace with:

cd /usr/src
# Preserve NextBSD Lever B (#278): bake the rtld-elf default search path.
# MUST precede buildworld so libexec/rtld-elf compiles with it.
printf '%s\n' \
  '.if ${.CURDIR:M*/libexec/rtld-elf}' \
  'CFLAGS+= -DSTANDARD_LIBRARY_PATH=\"/lib:/usr/lib:/usr/lib/system:/System/Library/Libraries:/usr/local/lib\"' \
  '.endif' >> /etc/make.conf

WORLD_FLAGS="WITHOUT_TOOLCHAIN=yes WITHOUT_TESTS=yes WITHOUT_LIB32=yes WITHOUT_DEBUG_FILES=yes"

./tools/build/make.py --cross-bindir="${CROSS_BINDIR}" \
  TARGET=$T TARGET_ARCH=$TA ${WORLD_FLAGS} -j"$(nproc)" buildworld

mkdir -p /stage
./tools/build/make.py --cross-bindir="${CROSS_BINDIR}" \
  TARGET=$T TARGET_ARCH=$TA ${WORLD_FLAGS} installworld \
  DESTDIR=/stage NO_ROOT=1 DB_FROM_SRC=1 METALOG=/stage/METALOG

NO_ROOT=1 + DB_FROM_SRC=1 reproduce, for the whole world, exactly the unprivileged Linux-runner semantics the curated build hand-rolled as install -N /usr/src/etc -U -M METALOG: metalog-mode install (record modes, no real chown/setuid on the rootless runner) with root/wheel resolved from the src tree's master.passwd/group. Kept unchanged: the container image resolution, the amd64/arm64 cross matrix, --cross-bindir (ports llvm19), and the entire publish continuous job.

3. WITHOUT_TOOLCHAIN + why no make distribution

confirmed buildworld completes with WITHOUT_TOOLCHAIN=yes and does not bootstrap base clang — because --cross-bindir supplies the external ports llvm19. The _bootstrap-tools/_legacy phase still runs (builds host sh/awk/m4/yacc/mtree/makefs… — unconditional, not a compiler); only _cross-tools's clang/lld/lldb are gated off by MK_TOOLCHAIN=no. The one hard requirement — pass the external compiler — is already met on every run.

installworld vs distribution is what keeps /etc out. installworld installs the built world and runs mtree to lay an empty directory skeleton (including a bare /etc, /var) — but zero config content. Only make distribution populates master.passwd, rc.conf, rc.d, pam.d, /var subtree, etc. We never run it. The Pack step then rm -rfs the empty skeleton as a hard guard. nextbsd/overlays own /etc and /var.

4. The strip contract (measured)

Derived by intersecting a stock FreeBSD 15.0-p9 base file set (cowsurgery) against all 565 paths in NextBSD-userland's plist — whole-list, exact-path, not sampled. Two buckets, policed differently.

4.1 Bucket A — collisions 3 files, auto-enforced

Paths NextBSD-userland also owns; pkg refuses two owners. Userland wins. The guard (§5) derives these automatically and fails on any unlisted new one.

PathWinner (why)
/usr/sbin/syslogdApple ASL syslogd (wired to com.apple.syslogd.plist)
/usr/include/Block.hApple Blocks header (matches libdispatch/CF ABI)
/usr/include/Block_private.hsame

Corrected assumption: libBlocksRuntime.so is not a collision — userland's lives in /usr/lib/system/, a different dir. The only Blocks overlap is the two headers.

4.2 Bucket B — superseded explicit, existence-asserted

No path collision, but NextBSD has replaced the function. All confirmed present on cowsurgery (so they'd land in buildworld) and confirmed absent & unused on the running NextBSD box.

Device attach + module load go entirely through kextd/IOKit. Stripping kld*/devd is safe; only kldxref stays in the candidate list pending the linker.hints check.

5. The self-policing guard scripts

Two checked-in scripts + two allowlists (scripts/collisions, scripts/superseded). The point: the strip-list cannot rot silently in either direction.

  • strip-collisions.sh — fetch NextBSD-userland's plist, intersect with the staged tree, strip the overlap. Fail the build if the overlap contains any path not in scripts/collisions. ⇒ a future FreeBSD import or new Apple daemon that starts sharing a path stops the build until someone records who wins — the exact inverse of tonight's silent-gap whack-a-mole.
  • strip-superseded.sh — strip each path in scripts/superseded, but assert it exists first. If FreeBSD renames/moves a tool, the stale entry fails the build so the list gets pruned.
# strip-collisions.sh (core)
curl -fsSL "$PLIST_URL" | normalise | sort -u > overlay        # userland's files
( cd "$STAGE" && find . \( -type f -o -type l \) ) | sed 's#^\./##' | sort -u > staged
comm -12 overlay staged > collide                              # what both ship
comm -23 collide <(sort scripts/collisions) > violations       # unapproved overlaps
[ -s violations ] && { echo "::error:: new base/overlay collision"; cat violations; exit 1; }
while read f; do rm -f "$STAGE/$f"; done < collide             # strip approved

6. Load-bearing: /etc guard + setuid from METALOG

Two things that were incidental in the curated build become primary contract mechanisms under a full installworld:

(a) The /etc / /var strip is now the guard, not belt-and-suspenders. Assert it worked:

rm -rf "$STAGE"/etc "$STAGE"/var "$STAGE"/root "$STAGE"/.profile "$STAGE"/.cshrc "$STAGE"/boot/kernel
# HARD ASSERT — nextbsd/overlays own these:
[ -z "$(ls -A "$STAGE"/etc "$STAGE"/var 2>/dev/null)" ] || { echo "::error:: /etc|/var not empty"; exit 1; }

(b) Setuid must be re-applied for the whole world, driven from METALOG. The rootless install -U records mode 04555 in the manifest but can't set the bit; the curated build hardcoded three files (su/login/shutdown). A full world has many more (passwd, crontab, ping, traceroute, chsh…). Drive it from the manifest:

awk '{ for(i=1;i<=NF;i++) if($i~/^mode=/){m=$i;sub(/^mode=/,"",m)}
       if(m~/^0?[2-7][0-7][0-7][0-7]$/){p=$1;sub(/^\.\//,"",p);print m,p} }' "$STAGE/METALOG" \
| while read -r mode rel; do [ -e "$STAGE/$rel" ] && chmod "$mode" "$STAGE/$rel"; done
rm -f "$STAGE/METALOG"

Otherwise su/login/passwd ship 0555 and silently fail. (Verify the mode regex against a real 15.0 METALOG before merge.)

7. Downstream: one line, the proof, the rollback

No downstream code addition needed — and this corrects the first-pass assumption. Collisions are stripped upstream, in the base build (strip-collisions.sh), so the nextbsd-base-*.tar.gz that nextbsd-pkg consumes already arrives clean of all 3 (verified against the PR #46 artifact: syslogd, Block.h, Block_private.h all absent). That makes the existing dedup at nextbsd-pkg/scripts/build.sh:52-58 (rm -f …/Block.h …/Block_private.h) a redundant no-op — the files it deletes aren't there anymore. So the change is a deletion, not an addition, and it's optional: remove those lines so collision policy lives in exactly one self-policing place instead of a stale partial copy that only knows Block.h. Adding syslogd there would be pointless.

The measured collision set is only 3 files, all handled upstream — but don't trust that, prove it:

# (A) SUPERSET — every path today's base ships must still exist (minus intended strips). Expect EMPTY:
comm -23 old.list new.list | grep -vf intended-strip.txt      # must be empty
# (B) NEW userland overlaps — must be fully absorbed by the dedup:
comm -12 new.list userland.list                               # expect only Block*.h + syslogd
# (C) real extraction test in a FreeBSD VM (NOT pkg -n):
pkg -r /tmp/root install -y NextBSD-everything                # expect zero file conflicts

Rollback is one git revert of the compat PR (+ the one-line build.sh edit) and one rebuild — continuous overwrites in place, no version burned, nothing pins an exact base version. srclist.txt survives in history; keep the removal a clean revertible commit.

8. CI cost

WITHOUT_TOOLCHAIN removes the single biggest chunk of a normal buildworld (compiling base clang/lld), so this is far cheaper than a stock full world:

 Standard runner (4 vCPU)Larger runner (8–16 vCPU)
buildworld (WITHOUT_TOOLCHAIN + trim)~35–50 min~12–22 min
installworld + strip + tar~4–8 min~2–4 min
wall-clock (arches parallel)~45–55 min (vs ~20 curated)~15–25 min (parity)

~2–2.5× on the default runner, fully recovered by moving to a larger runner — the recommended lever. (No ccache/NO_CLEAN benefit: fresh ephemeral container each run.)
