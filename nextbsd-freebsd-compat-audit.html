NextBSD — nextbsd-freebsd-compat 3-way audit

Every component the FreeBSD-compat closure installs into the NextBSD base (99 srclist.txt entries), cross-referenced against (1) what NextBSD overwrites with Apple-sourced code, and (2) what could be ported from Apple open source instead — each with a port-difficulty rating.

Summary

0 of 99 are currently overwritten by Apple code. NextBSD's Apple userland (libsystem_kernel, libdispatch, libxpc, configd, the *_cmds tools) installs into a parallel /usr/lib/system/ namespace or is vendored-but-deferred; the FreeBSD-compat set is the live base.

Three buckets emerge:

  • Actionable Apple swaps (Moderate) — reboot, shutdown, login, su, nologin, nmtree/mtree are already vendored from Apple system_cmds/shell_cmds/file_cmds but deferred behind missing shims (IOPMLib for power, BSM-audit + login.c PAM drift). Finishing those shims flips them over. caroot data could come from Apple's open security_certificates root store (Easy, data-only).
  • Already-Apple / same-upstream (Trivial–Easy, no work) — libbsm is OpenBSM (Apple-commissioned); the C++/builtins trio and the third-party libs (zlib, lzma, zstd, expat, sqlite3, ncurses, libedit, libarchive, xz) share the exact upstream Apple ships — no Apple-specific port buys anything.
  • Permanently FreeBSD (Impractical) — the ELF/loader/libc ABI (libc, rtld-elf, libthr — Apple's are Mach-O + XNU-coupled), the UFS tooling (newfs/tunefs/fsck_ffs — Apple has no UFS code; only newfs_hfs/apfs), the kernel-ABI libs (libkvm, libgeom, libjail, libcasper, libprocstat…), MIT Kerberos, and OpenSSL (Apple = closed corecrypto).

NextBSD-today takeaways

  • The Apple base is real and live: launchd (PID 1) + configd + IPConfiguration + DiskArbitration + mDNSResponder + hostnamed + kextd, the full /usr/lib/system/ Apple library stack, OpenPAM replacing FreeBSD-pam, Apple syslogd, and ~110 ported POSIX commands (most of shell_cmds/text_cmds/file_cmds/adv_cmds).
  • The deferred frontier is consistent: power/identity tools (reboot/shutdown/login/su) wait on IOPMLib + BSM; file tools (cp/mv/ls/chmod/mtree) wait on clonefile/copyfile/libacl/xattr; process tools (ps/w/killall) wait on kinfo_proc/PROCARGS2 shims. Until then those paths run the FreeBSD-compat tool.
  • Permanently not-Apple on ELF: the Mach-O/kdebug-only introspection family (arch, lsmp, vm_stat, fs_usage) and CLIs with no buildable source (jq).
