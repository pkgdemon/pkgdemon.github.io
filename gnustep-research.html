GNUstep Research

  • WebKit v5 — Cocoa-native GNUstep porting plan Plan v5 Port the macOS Cocoa WebKit to GNUstep using native core libs (libs-opal, libs-quartzcore, libs-corebase, libs-av). No GTK, no GLib, no Skia, no GStreamer. Complete framework gap analysis, feature-disable map, minimal CMake flags, and 8-phase roadmap.
    • libs-corebase — CoreFoundation gaps Sub-plan Add CFNotificationCenter, CFPreferences, CFStringTokenizer to libs-corebase. ~3 new files, ~700 LOC.
    • libs-opal — CoreGraphics, CoreText & ImageIO gaps Sub-plan Missing CG path/gradient functions, CoreText font fallback cascade, Apple SPI stub headers. ~5-8 functions to implement.
    • libs-quartzcore — QuartzCore/CoreAnimation gaps Sub-plan Merge 6 DTW-Thalion PRs, add CALayer.frame, CADisplayLink, CATransaction.completionBlock. Most gaps bypassed by software rendering initially.
  • How Menus Work: macOS vs GNUstep Comparing menu rendering architecture between macOS and GNUstep.
  • Who draws the macOS menu bar? Ownership and rendering of the macOS menu bar.
  • WindowServer.app Development Plan Native GNUstep display server for Linux using KMS/DRM and GPU compositing.
  • Gershwin WindowManager QA Plan Two-track QA plan: per-PR manual smoke checklist plus a phased automated test suite.
